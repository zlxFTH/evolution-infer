我建议保留现在的两步起点定位。**确定 \(l\) 之后，把终点预测改成给候选复制区间打分**。模型每考虑一个可能的末尾 token \(e\)，都能看到从 \(l\) 到 \(e\) 的内容，最后输出 \(r=e+1\)。

现在的设计用 `PairMLP(q_end, C[m])` 选终点块。假设起点在第 2 块，正在给第 8 块打分，第 3～7 块的内容没有被显式汇总进这个候选的特征。你想补的就是这部分信息。[当前设计](/Users/zlxfth/Files/evolution-infer/repo/doc/copy_locator.md)

### 1. 怎么表示一个候选区间

第一版我会给打分器三个输入。

| 输入             | 怎么算                                | 告诉模型什么                               |
| ---------------- | ------------------------------------- | ------------------------------------------ |
| 当前任务 \(u\)   | \(\mathrm{MLP}_q([q, X_l])\)          | 现在要生成什么，从哪里开始复制             |
| 整段内容 \(v_e\) | 对 \(l\) 到 \(e\) 的 token 特征取均值 | 如果停在这里，整段复制了什么               |
| 末尾特征 \(X_e\) | 取最后一个被复制 token 的特征         | 具体停在什么地方，例如换行、右括号或标识符 |

可以先用一个小 MLP 把每个 token 投影到 128 维，再做区间均值。完整公式很短：

\[ H_j=\mathrm{MLP}_{\mathrm{token}}(X_j),\qquad v_e=\frac{1}{e-l+1}\sum_{j=l}^{e}H_j,\qquad s(l,e)=\mathrm{MLP}_{\mathrm{score}}([u,v_e,X_e]). \]

两个打分阶段都可以用 `Linear → SiLU → Linear`，各自学习参数。这里的非线性有具体用途：在求均值前学习哪些 token 特征值得保留，在求均值后学习什么样的区间内容和末尾适合当前任务。单独保留 \(X_e\) 也很重要，长代码段末尾多一个换行，整段均值可能几乎不变。

区间均值可以用**前缀和**计算。缓存 \(P_t=\sum_{j<t}H_j\)，每个候选只需算 \((P_{e+1}-P_l)/(e-l+1)\)。这里的“纯净”指参与聚合的位置严格落在 \([l,e]\)。如果你还要求同一串源码放在哪里都得到相同的内容特征，可以让 \(H_j\) 读原始 token embedding，因为目前的 \(X_j\) 已经带有上文信息。

### 2. 怎么先选块，再选精确终点

**选块时，我建议每块先试三个可能的末尾**。取这块里第一个合法位置、中间位置、最后一个可见位置，分别给三个真实区间打分，最高分作为块分数。这样每个候选都有明确的末尾，也不会默认把终点块整块算进复制内容。

**选中块后，再给块里所有合法末尾打分**，最多 32 个。两个阶段都能并行。每块试三个位置是速度与召回率之间的设计选择，需要用验证集测终点块召回率，因为最佳末尾可能恰好落在两个采样点之间。

举个同块的例子。块大小为 32，已知 \(l=22\)，最短复制长度为 5：

| 候选终点块                      | 粗选时试哪些末尾 \(e\) | 选中后精确检查 |
| ------------------------------- | ---------------------- | -------------- |
| 第 0 块 `[0,32)`，与 \(l\) 同块 | 26、28、31             | 26～31         |
| 第 1 块 `[32,64)`               | 32、47、63             | 32～63         |

如果真实区间是 `[22,30)`，模型先选第 0 块，再选 \(e=29\)。如果是 `[22,32)`，末尾 \(e=31\) 也属于第 0 块。**块号始终按最后一个复制 token \(r-1\) 计算**，这样刚好停在块边界也能处理。

### 3. 同块能不能学到，训练数据比加一层 MLP 更关键

我数了你本地的 CopyGen code 训练集。原始 **836** 条复制区间里，只有 **13** 条起点和末尾同块。按你的方案把长区间展开成后缀，保留剩余长度至少 5 的位置，可以得到 **10,832 / 216,040** 个同块正样本，约 **5.0%**。所以训练时可以在正样本中分别抽取同块和跨块样本。评估时给定真实 \(l\)，分开看两组的**终点块命中率**和**精确 \(r\) 命中率**，就能分清错误出在选块还是块内定位。[本地训练数据](/Users/zlxfth/Files/evolution-infer/repo/data/copygen_train_code.jsonl)

相关工作里，*Copy That!* 在代码编辑中直接把复制整个区间建模为一次动作。Lee 等人则把**边界特征和区间内部特征**组合起来给文本区间打分。前者对应你的复制目标，后者更直接支持你提出的“让模型看到中间这一段”。上面的三级采样和区间均值是针对你的推理开销提出的设计，实际收益还要和现有 `PairMLP` 对照测。[Copy That!](https://arxiv.org/abs/2006.04771) · [Lee et al., EMNLP 2017](https://aclanthology.org/D17-1018/)
