## 数据格式

采用 $(i, l, r)$

`.jsonl` 格式，字段如下

+ `id`：数据编号
+ `prompt`：提示词
+ `cot`：思维链
+ `output`：模型输出
+ `prompt_ids`：提示词 token 序列
+ `cot_ids`：思维链 token 序列
+ `output_ids`：模型输出 token 序列
+ `copy_cot`：
+ `copy_output`：

例子

```json
{
  "id": "sample_0001",
  "prompt": "原代码与修改指令文本（仅供人眼查阅）",
  "cot": "思考过程文本，关闭 CoT 时为空串",
  "output": "最终输出代码文本",
  "prompt_ids": [1, 2, 3, ],
  "cot_ids": ["... 思考段 tokens（关 CoT 时为 []）"],
  "out_ids": ["... 正式输出 tokens 含末尾 <|im_end|>"],
  "spans": [
    [0, 18, 95, []],
    [112, 460, 488, []]
  ]
}
```
